# CS 210 Project Three – Grocery File Program  

## Project Summary  
In this project, I created a program in C++ that reads a list of grocery items from a file, counts the frequency of each item, and outputs the results to both the console and an external file. The goal was to practice file input/output, working with maps, and formatting output in multiple ways (list and histogram). This project solved the problem of taking raw data and transforming it into an organized, user-friendly report.  

## What I Did Well  
I did particularly well in designing a menu system that allowed users to choose between different output views (item frequency or histogram). I also made sure my code was readable with consistent indentation, meaningful variable names, and comments explaining the logic.  

## Areas for Improvement  
One area for improvement would be implementing stronger error handling. For example, if the input file was missing or contained unexpected data, my program could have handled it more gracefully. Adding validation and exception handling would make the program more secure and reliable.  

## Challenges and How I Overcame Them  
The most challenging part of this project was making sure the program correctly updated and displayed the histogram. At first, spacing and alignment made the output hard to read. I overcame this by experimenting with string formatting, testing small changes, and reviewing examples from zyBooks until the output matched the expected format.  

## Transferable Skills  
From this project, I strengthened my skills in:  
- Reading and writing external files in C++  
- Using data structures like maps to count occurrences  
- Building menu-driven programs  
- Debugging formatting issues and validating results  
These skills are directly transferable to future projects where data must be processed, organized, and displayed to users.  

## Maintainability and Readability  
I kept the program maintainable and adaptable by writing separate functions for different tasks, which makes the code modular and easier to update in the future. I also added descriptive comments above each function, which will help anyone reading the program understand its purpose quickly. This approach makes it easier to extend the program later, such as adding new menu options or different output formats.
